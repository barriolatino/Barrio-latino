# Montage publicitaire

Outils : profil `publicite`, presets `pub_verticale`, `pub_horizontale`, `--end-text` pour l'appel à l'action, `--title`.

## Règles concrètes
- Le produit ou service apparaît dans les 2 premières secondes (`hook = meilleur_plan`).
- Plans de détail sur la parole (`broll_cutaways`, couverture 50 %).
- Le texte de fin / appel à l'action est **fourni par le client**, mot pour mot. Si absent : aucun texte inventé, le signaler.
- Versions : `revise "Fais une version de 15 secondes"` puis 30 s ; chaque version est une timeline distincte.
- Logo : à déposer dans `assets/logos/` avec ses droits ; non incrusté automatiquement (à faire valider).

## Limites honnêtes
Le système ne reconnaît pas le produit dans l'image : « mets en valeur le produit » augmente la place des plans d'illustration, c'est une approximation signalée.

## Ne pas utiliser
Pour un contenu journalistique ou une interview (pas de mise en scène commerciale des propos).
