# Outils

| Fichier | Rôle |
|---|---|
| `factory.py` | CLI : `calendar`, `next`, `build`, `review`, `export`, `pick`, `bank`, `combine`, `stats` |
| `bank.py` | banque d'idées : sélection, rotation, anti-répétition, apprentissage |
| `render.py` | rendu : cartes, animation, vidéo H.264/AAC, sous-titres libass, cover |
| `check.py` | tests de structure (Phase 1) : config, base de contenu, commandes, `.env.example` |

Les sous-dossiers (`research/`, `content/`, `images/`, `voice/`, `subtitles/`, `video/`,
`carousel/`, `quality-control/`) accueilleront chaque module au fil des phases 2 à 5.
Chaque README dit où se trouve la fonction aujourd'hui.
